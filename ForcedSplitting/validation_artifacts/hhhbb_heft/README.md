# HEFT hhhbb forced-splitting validation artifact

`b_pt_rank_grid.png` is the 2x4 ranked-b-quark transverse-momentum comparison
generated on Odysseus by `ForcedSplitting/validation_hhhbb.py`.  It compares

- `gg -> hhhg`, followed by a forced `g -> b bbar` splitting; and
- direct `gg -> hhh b bbar` production,

in the HEFT `m_t -> infinity` validation setup.  Each panel is normalized
independently and includes weighted-MC statistical error bars.  The large
panel number identifies the b-quark pT rank from 1 through 8.
